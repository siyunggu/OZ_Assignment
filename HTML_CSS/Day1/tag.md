

# HTML 태그 정리

### 1. \<p>
문단 태그


### 2. list 관련 태그
- \<ul> <br>
unordered list로 순서가 없는 리스트 형식
- \<ol><br>
ordered list로 순서가 있는 리스트 형식 <br>
숫자의 경우엔 start라는 속성으로 시작값 설정 가능함
그 외에도 i, I a, A 등이 있다.

### 3. \<input>
form 형식에서 사용자로부터 데이터를 입력 받을 때 사용하는 태그

### 4. \<img>
- 브라우저 링크 주소로 이미지 가져오는 경우
img 태그를 연 후 링크 주소를 붙여넣고, alt에는 사진에 대한 정보를 간단히 적음. alt는 사진이 깨지는 경우나 시각장애인을 위해 어떤 사진인지 알게 해주는 역할을 함.

- 로컬에서 이미지 가져오는 경우
vs code에 이미지를 붙여넣고, 이미지 파일명을 이미지 태그에 붙여넣음. (주의⚠️파일명 앞에 ./ 꼭 적어주기)

### 5. \<table>
table 태그 안에 자식 태그들을 작성
- table head<br>
\<thead> : 테이블 헤드 <br>
\<tr> : 테이블 헤드를 행으로 작성하기 위한 태그<br>
\<th> : 실제 테이블 헤드명을 기입<br>


- tabel body<br>
\<tbody> : 테이블 바디(데이터 입력)<br>
\<tr> : 한 개의 행마다 태그 입력<br>
\<td> : 한 개의 셀 값 입력<br>
